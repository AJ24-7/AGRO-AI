# 🌿 AgroPilot AI – Smart Farming Assistant

AgroPilot AI helps farmers manage farms, analyze soil reports, get AI crop &
fertilizer recommendations, detect crop diseases, and manage tractors — all
from a modern green-themed dashboard.

> B.Tech Final Year Project | React + FastAPI + PostgreSQL + ML

---

## ✨ Working Features

### 🔐 Authentication
- User registration with email validation and password strength indicator
- JWT-based login / logout (OAuth2-compatible)
- Protected routes — all dashboard pages require a valid token
- `GET /api/auth/me` — fetch current user profile

### 👤 Farmer Profile
- View and edit profile (name, village, district, state, total land area)
- Initials-based avatar with state & land-area badges

### 🌾 Farm Management
- Full CRUD — create, view, edit, and delete farms
- Interactive Leaflet map with polygon boundary drawing
- Auto area calculation (acres) from GPS boundary points
- Centroid calculation and boundary-point visualisation
- Location intelligence via Nominatim reverse-geocoding
- Live weather data per farm via Open-Meteo API
- Regional crop suggestions based on state, temperature, precipitation & season
- `POST /api/farms/location-insight` — combined weather + crop + boundary data

### 🗺️ Plot Management
- Full CRUD for plots linked to a farm (name, area, soil type)
- View all plots across all farms from a single endpoint

### 🧪 Soil Analysis (OCR)
- Drag-and-drop soil-report image upload with preview
- Tesseract OCR extracts N, P, K, and pH values with regex parsing
- Color-coded nutrient bars relative to target ranges
- Raw OCR text displayed alongside parsed values
- Full analysis history sorted by date

### 🌱 AI Crop Recommendation
- Scikit-Learn RandomForest model — input N, P, K, pH → recommended crop + confidence %
- Optional GPS input (auto-filled via browser geolocation or latest farm coordinates)
- Enriched result: crop image, live weather, Google News RSS articles, location label
- Location-based seasonal recommendations (40+ Indian states, 4 seasons)
- Dashboard crop feed — top 4 unique recommended crops with enriched data
- Crop tutorial stages: preparation → sowing → irrigation → nutrition → protection → harvest → post-harvest
- Auto-creates in-app notification on each recommendation

### 🍃 Disease Detection
- EfficientNet-B0 neural network (Keras) with Test-Time Augmentation
- Drag-and-drop leaf image upload with preview
- 40+ disease types across Apple, Corn, Tomato, Potato, Grape, Pepper, Soybean, Strawberry, and more
- Confidence badge: High / Moderate / Low
- Full treatment guidance per detected disease
- Complete detection history with delete-individual-record support
- Auto-creates in-app notification on each detection

### 🧴 Fertilizer Recommendation
- Rule-based engine comparing current N, P, K against per-crop targets
- Supported crops: Rice, Wheat, Maize, Cotton, Sugarcane, and more
- Recommends Urea (nitrogen), DAP (phosphorus), Organic compost (potassium)
- Output: fertilizer names, quantities (kg/ha), and deficiency reasons
- Nutrient comparison bars with color-coding
- Auto-creates in-app notification on each recommendation

### 🚜 Tractor & Equipment Management
- Full CRUD for user-owned tractors (brand, model, registration number, purchase year)
- Equipment catalog with live merchant price aggregation
- Category browsing: Tractor, Rotavator, Seed Drill, Power Tiller, Harvester, Sprayer, Irrigation, Tillage, Thresher
- Search and filter by category; prices shown in INR (₹)
- Direct product links and last-updated timestamps

### 🔔 In-App Notifications
- Automatic notifications generated by: crop recommendations, disease detections, fertilizer suggestions
- Mark individual notifications as read
- Sorted by date, latest first; type badges (disease / crop / fertilizer)

### 📊 Dashboard Analytics
- Summary cards: total farms, plots, tractors, soil reports, disease detections
- Bar chart — disease distribution (count by disease type)
- Pie chart — crop recommendation distribution
- Crop feed with images, weather, and news; manual refresh with loading states
- Recharts-powered visualisations with graceful API-failure fallbacks

### 🤖 AI Farming Chatbot
- Context-aware responses using latest farm location, weather, and recommended crops
- Automatic intent detection: crop, fertilizer, disease, soil, weather, farm, market, greeting
- Web-search integration and curated knowledge-base links (FAO, ICAR, eNAM, etc.)
- Action-item generation per intent
- Persistent chat history with session IDs
- `GET /api/chatbot/history` — retrieve previous messages for a session

### 🌐 Internationalisation
- `LanguageContext` — multi-language support scaffolded via `i18n/translations.js`

## ⚙️ Environment Configuration

- **Backend**: create a `.env` file in the `Backend/` folder with required variables (e.g. `DATABASE_URL`, `SECRET_KEY`). Create a `.env.local` alongside it for machine-specific overrides — the backend loads `.env` first, then `.env.local`.
- **Frontend**: Vite loads `.env` and `.env.local` automatically. Prefix variables with `VITE_` (e.g. `VITE_API_URL`) and access via `import.meta.env.VITE_API_URL`.

Add sensitive files to `.gitignore` (the repo already ignores `Backend/.env`; also add `.env.local`).
